# 渲染本轮剧情

依据本轮大纲（情节弧 / 剧情发展 / 人物塑造 / 战斗 / 设定信息 / 数值结算）与新旧角色卡变化（initial→final），把大纲意图渲染成正文。

## 输入利用
- 「情节弧」节奏（骨架见 system）确定本章叙事节奏；「剧情发展」是叙事主干大纲，直接据此展开正文故事。
- 「人物塑造」的动机与转变融进动作与对白，不直述心理。
- 「设定信息」节是 NPC / 地点 / 物品 / 技能的描写素材，直接取用其 fact，**不自创设定细节**。设定只取自本节，与大纲中记录的设定一致。
- 数值结算的 initial→final 反映为状态变化（受伤、力竭、获物、升级）。
- 「游戏时间」节提供本轮起止时间，正文据此标记。

## 战斗（跟大纲）
- **战前轮**：渲染战场环境与敌情，以 2-4 个策略选项结尾（不交战，机制见 system）。
- **战斗轮**：玩家给出策略后，一轮渲染完整场战斗（机制见 system）。
- **大纲中已包含本轮 Roll 函数的判定结果（格式：`[Roll: <purpose>]` + 骰值详情）**。正文从中读取并展述——以 `[Roll: 命中判定] 1d20+5=18 vs DC 14 → 成功` 等格式将骰值、调整值、DC 与成败写入叙事，随后续写动作效果。大成功 / 大失败 / 暴击着重渲染。

## 数字尺度
叙事为主，关键时刻露数值（HP 变化、伤害数）；不堆砌数字、不报整张面板。

## 结构
- 开头以 `【第N日·H时】` 标记本章起始游戏时间（如`【第1日·14时】`），自然衔接上轮，不用「上次说到」式 recap。
- 结尾落实大纲余韵的断章钩，以 `【第N日·H时】` 标记本章结束游戏时间，并给出 2-4 个**具体措辞**选项（方向取自大纲，措辞由 render 定——见 system 选项契约）。
- 语言风格见 system 末尾「默认语言风格」；本章若大纲点了特定风格，见当前消息末尾加载的风格正文。
