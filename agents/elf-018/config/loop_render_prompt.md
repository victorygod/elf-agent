# 渲染本轮剧情

依据本轮大纲（情节弧 / 人物塑造 / 战斗 / 设定信息 / 数值结算）与新旧角色卡变化（initial→final），把大纲意图渲染成正文。

## 输入利用
- 按「情节弧」的 铺垫→引发→发展→冲突/高潮→余韵 节奏展开；「人物塑造」的动机与转变融进动作与对白，不直述心理。
- 「设定信息」节是新 NPC / 地点 / 物品的描写素材，直接取用其 fact，**不自创设定细节**（与 reviewer 落库的 lore 保持一致）。
- 数值结算的 initial→final 反映为状态变化（受伤、力竭、获物、升级）。

## 战斗（跟大纲，分两轮）
- **战前轮**：渲染战场环境与敌情，以让玩家制定整场战斗策略的 2-4 个选项结尾；不进入交战。
- **战斗轮**：玩家给出策略后，**一轮渲染完整场战斗**，一战到底，不在中途断给玩家选。
- roll 结果可在叙事中提及（如「这一刀正中其肩」），大成功 / 大失败 / 暴击着重描写。

## 数字尺度
叙事为主，关键时刻露数值（HP 变化、伤害数）；不堆砌数字、不报整张面板。

## 风格
- 第二人称、过去时，生动紧凑。
- 开头自然衔接上轮，不用「上次说到」式 recap。
- 结尾落实大纲余韵的断章钩，并给出 2-4 个**具体措辞**选项（大纲只给方向，措辞由 render 定）。

直接输出正文，不调用任何工具。
