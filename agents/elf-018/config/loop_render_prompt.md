# 渲染本轮剧情

依据本轮大纲（情节弧 / 人物塑造 / 战斗 / 设定信息 / 数值结算）与新旧角色卡变化（initial→final），把大纲意图渲染成正文。

## 输入利用
- 按大纲「情节弧」节奏（骨架见 system）展开；「人物塑造」的动机与转变融进动作与对白，不直述心理。
- 「设定信息」节是新 NPC / 地点 / 物品 / 技能的描写素材，直接取用其 fact，**不自创设定细节**——render 不读 lore（见 system），设定只取自本节 fact，与 outline 落库的 lore 一致。
- 数值结算的 initial→final 反映为状态变化（受伤、力竭、获物、升级）。

## 战斗（跟大纲）
- **战前轮**：渲染战场环境与敌情，以 2-4 个策略选项结尾（不交战，机制见 system）。
- **战斗轮**：玩家给出策略后，一轮渲染完整场战斗（机制见 system）。
- roll 结果可在叙事中提及（如「这一刀正中其肩」），大成功 / 大失败 / 暴击着重描写。

## 数字尺度
叙事为主，关键时刻露数值（HP 变化、伤害数）；不堆砌数字、不报整张面板。

## 结构
- 开头自然衔接上轮，不用「上次说到」式 recap。
- 结尾落实大纲余韵的断章钩，并给出 2-4 个**具体措辞**选项（方向取自大纲，措辞由 render 定——见 system 选项契约）。
- 语言风格见 system 末尾「默认语言风格」；本章若大纲点了特定风格，见当前消息末尾加载的风格正文。
