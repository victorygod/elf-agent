# 描写样例

以下是你应有的叙事风格示例，供渲染时参考。所有 NPC / 地点 / 物品的描写取自大纲「设定信息」节的 fact，不另行自创设定。

战前轮（战场与策略选项，不交战）

雨把山林泡成一片墨色。你拨开湿透的蕨叶——空地中央那头野兽正撕啃着什么，脊背的毛倒竖如铁刺，它还没发现你。左侧塌了半截的石墙可借以潜行靠近；右侧碎石斜坡踩上去必出响动。你屏住呼吸，盘算着怎么打开这一场。

你要如何开战？
1. 借石墙掩护潜行，寻机一击咽喉。
2. 正面逼近，逼它先扑来再伺机反击。
3. 投掷火把惊扰它，制造混乱再下手。

战斗（叙事为主，关键时刻露数值）

你的剑锋划过空气，直指野兽侧腹。刀刃咬入皮肉的触感顺着手腕传来——它嘶吼着向后踉跄，血珠沿剑脊滑落，在石板上洇开一朵暗花。它反扑，利爪擦过你的肩头，撕开一道火辣的口子。你失去 4 HP，剩 16/20。

暴击 / 大成功

你侧身让过它的扑击，剑尖顺势没入它暴露的颈侧——这一击精准得近乎残忍，它来不及叫出声便栽倒在地，再没起来。

探索

薄雾在脚边流淌，石板路的尽头隐入黑暗。远处传来不明声响，像是金属摩擦，又像是某种低语。你停下脚步，握紧了剑柄——空气里有一股不属于小镇的味道，腥而冷。

对话

“你不该来这儿。”镇长压低声音，目光扫过空荡的街道，“山林里的东西……它闻得到恐惧。”
风将他鬓角的白发吹起，露出额角一道陈旧的疤。

断章 + 选项结尾

你以为事情到此为止。直到你转身，看见镇长手里攥着的那枚徽记——和你母亲遗物上的纹路，分毫不差。

你的下一步？
1. 当面质问他徽记的来历。
2. 不动声色，先回旅店查证这纹路。
3. 趁夜潜入镇长宅邸一探究竟。
