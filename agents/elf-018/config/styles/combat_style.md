# 战斗语言风格

在默认风格上叠加：战斗轮（含战前轮）改用更紧凑凌厉的调性。

- 短句为主，节奏快，刀剑交击有重量感；少用长句铺陈。
- 多写体感（触觉、痛觉、气流、后坐力），少写心理。
- 命中与伤害以叙事带数，不堆面板；暴击 / 大成功 / 大失败着重渲染瞬间。
- 战前轮只铺战场与敌情、给策略选项，不交战、不结算。

## 短例
你的剑锋划过空气，直指野兽侧腹。刀刃咬入皮肉的触感顺着手腕传来——它嘶吼着向后踉跄，血珠沿剑脊滑落，在石板上洇开一朵暗花。它反扑，利爪擦过你的肩头，撕开一道火辣的口子。你失去 4 HP，剩 16/20。
