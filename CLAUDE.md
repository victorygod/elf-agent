## No backward compatibility
Delete outdated code directly. No compatibility layers, no migrations, no fallbacks. If it's being replaced, remove the old — dead code is tech debt.

## Modularity
Keep components focused with clear boundaries. Separate concerns — don't let cross-cutting logic leak into unrelated modules.

## Pattern adoption
Before solving a problem, look at how mature products handle it. Adopt proven patterns over reinvention.
